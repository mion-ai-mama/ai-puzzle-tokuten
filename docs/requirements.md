# AIで作る「オリジナルパズル販売」スタートガイド｜Instagramリール特典ページ 要件定義書

## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論）＝静的サイト
- 操作者: ブラウザのエンドユーザー（リール→DM→オプチャ→特典まとめ経由のスマホ閲覧者）
- AI本体(プロンプトY): なし（読者が自分のAIで使うプロンプトを掲載するのみ）
- MCP: なし / 自社DB: なし / フロントUI: あり / 動的変数: なし
- 種別: Web型（静的サイト）
- 配布: マイ専用（`mion-ai-mama/ai-puzzle-tokuten`・GitHub Pages）

## 1. 目的・ターゲット

リール流入の40〜50代・AI初心者・在宅で収入を増やしたい女性に、「AI画像→Printifyでパズル商品化→販売→3つの工夫」を初心者向けに解説する無料特典。リールで訴求した「月5万で終わらせない3つの工夫」を回収する。収益保証表現は使わない。

## 2. ページ構成（P-001 index.html・文章の単一の源）

ファーストビュー／導入／全体像図解（Printify=作る側・Etsy等=売る場所）／STEP1 テーマ決め＋プロンプト①／STEP2 画像生成＋プロンプト②＋追加指示＋画像チェックリスト／CTA①／STEP3 Printify＋確認チェックリスト／STEP4 販売先＋プロンプト③／3つの工夫（①海外＋プロンプト④ ②横展開 ③SNS＋プロンプト⑤）／まとめ図解／3日プラン／FAQ／重要な注意事項／まとめ／CTA②＋固定ボタン

## 3. 方針

- 確認できない情報（Printify仕様・料金・対応地域、Etsy料金、AIプラン制限、規約）は記載せず「最新の公式情報を確認」とする
- 競合の文章・プロンプトはコピーしない（オリジナル）
- CTAは兄弟ページと同じ標準構成（教科書＋AI収益化サポート会／個別相談・CTA①②・固定ボタン）。OGP画像は設定しない
- 配色は大人ピンク×アイボリー（POINT=淡い黄、注意=淡い赤を補助色として使用）

## 4. 受け入れ条件

1. スマホ幅で横スクロールなし 2. 全プロンプトのコピーボタン動作・「コピーしました！」表示 3. CTA表示 4. リンク切れなし 5. レスポンシブ 6. 誤字脱字なし 7. プロンプトの書き換え部分（【】）が明示されている 8. 「月5万」が収益保証に見えない（目標の一例と明記）
